#  My First Hacking Tools

I built these 4 tools while learning ethical hacking!

##  Password Generator
Creates strong random passwords.

##  Subdomain Finder
Finds hidden subdomains of a website.

##  Directory Brute Forcer
Finds secret folders on websites.

##  Web Scraper
Extracts data from websites (titles, links, images).

##  How to use
1. Clone this repo
2. Run `python3 tool_name.py`
3. Follow the prompts!

##  Built with
- Python 3
- Requests
- BeautifulSoup4
